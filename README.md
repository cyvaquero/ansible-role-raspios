# Ansible Role: RaspiOS

The RaspiOS Ansible role manages raspi-config settings on RaspiOS

## Availability

The RaspiOS Ansible role is currently only available as a standalone role.

## Setup

Note that the install instructions in this document describe installation of the standalone RaspiOS Ansible role. 

### Requirements

> Note: These requirements have been tested. Please submit a documentation issue if you have tested on other versions not listed below.

- Supported hardware:
    - Raspberry Pi 3
    - Raspberry Pi 3B+
    - Raspberry Pi 4
    - Raspberry Pi 5
- Supported versions of RaspiOS
    - bookworm
    - bookworm-lite
- Ansible v2.18+
